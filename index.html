project-collections-gradle-settings-plugin • v5.3.0

Nested Project Collections

A Gradle Settings convention plugin streamlining calls to Settings.include(...) based on nested collections of subprojects with automatic container flattening.

download Get Started menu_book API Documentation

Features

folder_open

Recursive Collection

Eliminate hundreds of manual include(...) declarations by specifying top-level directory roots and target traversal depth.

layers_clear

Avoid Empty Projects

Adheres to Gradle best practices by flattening intermediate project paths (e.g. :features:auth:login to :features-auth-login), eliminating empty container projects.

filter_alt

Filtering & Specs

Apply custom fileSpec predicates to selectively filter subproject directories based on file names, directory contents, or custom criteria.

speed

Configuration Cache Safe

Fully integrated with Gradle 8.x/9.x Configuration Cache and Project Isolation models using lazily resolved properties.

verified

Lowest JDK Baseline

Compiled targeting Java 17 bytecode (class version 61.0), guaranteeing broad compatibility with Gradle runners on JDK 17, 21, 25, or 26+.

swap_horiz

Custom Transformations

Supply custom ProjectNameMapper lambdas to establish bespoke project naming rules across enterprise repositories.

terminal Setup & Application

Apply the plugin directly in your settings.gradle.kts:

// settings.gradle.kts
plugins {
    id("dev.fnc314.gradle.plugins.settings.project-collections-gradle-settings-plugin") version "5.3.0"
}

Or declare it within your gradle/libs.versions.toml:

[plugins]
project-collections = { id = "dev.fnc314.gradle.plugins.settings.project-collections-gradle-settings-plugin", version = "5.3.0" }

code DSL Configuration 

// settings.gradle.kts
projectCollections {
    // Traverse 'components' and 'design-system' 1 level deep
    listOf(
        "components",
        "design-system",
    ).onEach { it toDepthOf 1 }

    // Traverse 'features' 3 levels deep
    "features" toDepthOf 3

    // Optional fileSpec filtering
    fileSpec.set { file: File ->
        !file.name.startsWith("_") && !file.name.startsWith(".")
    }

    // Flattens intermediate container projects (default: true)
    flattenMiddleProjects.set(true)
}
